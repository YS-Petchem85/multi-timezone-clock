# 🌍 멀티 타임존 디지털 시계

전 세계의 여러 시간대를 동시에 확인할 수 있는 인터랙티브 웹 기반 디지털 시계입니다.

## 🎯 주요 기능

### 1. **다중 시간대 표시**
- 전 세계 주요 도시의 현재 시간 표시
- 각 도시별 날짜 정보 포함
- UTC 오프셋 표시

### 2. **시간대 관리**
- 드롭다운에서 시간대 선택하여 추가
- 동적 시계 카드 생성
- 시계 카드에서 간편하게 제거 가능
- 초기화 버튼으로 기본 시계 복원

### 3. **실시간 업데이트**
- 매초 자동 업데이트
- 부드러운 애니메이션
- 정확한 시간 표시

### 4. **기본 시계**
- 서울 (한국)
- 뉴욕 (미국 동부)
- 런던 (영국)

## 🎮 사용 방법

1. **시간대 추가**
   - 드롭다운 메뉴에서 원하는 시간대 선택
   - "추가" 버튼 클릭 또는 드롭다운에서 선택
   - 새로운 시계 카드가 그리드에 추가됨

2. **시계 제거**
   - ��계 카드 우상단의 "×" 버튼 클릭
   - 해당 시계가 제거됨

3. **초기화**
   - "초기화" 버튼으로 기본 시계 3개 복원
   - 추가된 모든 시계 제거

## 🔧 기술 스택

- **HTML5**: 구조 및 마크업
- **CSS3**: 반응형 디자인, 그라데이션, 애니메이션
- **JavaScript (Vanilla)**: 
  - Intl API를 사용한 정확한 시간대 변환
  - 동적 DOM 조작
  - 실시간 업데이트 로직

## 📱 반응형 디자인

- 데스크톱: 4-6개 시계 그리드
- 태블릿: 2-3개 시계 그리드
- 모바일: 1개 시계 풀 너비

## 🎨 디자인 특징

- 모던한 그라데이션 배경
- 레트로 감성의 디지털 시계 디스플레이
- 호버 효과로 인터랙티브한 카드
- 부드러운 애니메이션과 트랜지션
- 다크 모드 자동 지원
- 녹색 LED 효과의 시간 표시

## 🚀 시작하기

## 💡 기능

### Intl API 사용
- 자바스크립트의 Intl 객체를 사용하여 정확한 시간대 변환
- 각 시스템의 표준 시간대 데이터베이스 활용
- 일광절약시간(DST) 자동 처리

### 실시간 업데이트
- `setInterval`로 매초 시간 업데이트
- 효율적인 DOM 업데이트
- 자연스러운 사용자 경험

## 📊 기술 세부사항

### 시간대 오프셋 계산
```javascript
// UTC 기준 오프셋 계산
const offset = (tzTime - utcTime) / (1000 * 60 * 60);
```

### 정확한 시간 포맷팅
```javascript
// Intl.DateTimeFormat 사용
const formatter = new Intl.DateTimeFormat('en-US', {
    timeZone: timezone,
    hour: '2-digit',
    minute: '2-digit',
    second: '2-digit'
});
```
